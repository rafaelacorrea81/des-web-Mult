# GitHub e VS Code

Conceitos e configurações básicas — o ambiente e o versionamento que todo desenvolvedor usa no dia a dia.

**Curso Técnico em Multimídia** · Material complementar — Desenvolvimento Web

## Como usar este material

Este material complementa a apostila **"Primeiros Passos na Web"** com um mergulho mais profundo em duas ferramentas que você vai usar todos os dias: o editor de código **VS Code** e o sistema de versionamento **Git/GitHub**.

- Siga as unidades **na ordem** — os comandos de uma unidade pressupõem que você já fez a anterior.
- Todo passo está descrito com o **nome exato** do botão, menu ou comando. Se a tela que você vê tiver um texto diferente, pare e confira se não pulou um passo anterior.
- Toda unidade prática tem uma seção **"Vídeo de apoio"**.
- Este material pressupõe que você já sabe o que são HTML, CSS e JavaScript. Se ainda não viu o básico de desenvolvimento web, comece pela apostila **"Primeiros Passos na Web"**.
